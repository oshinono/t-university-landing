# Т-Университет

Node.js 22+: `npm ci && npm run build && npm test`. Для просмотра: `python3 -m http.server 8000`, затем http://localhost:8000/.

Править шаблоны в `src/`, не сгенерированные `index.html` и `course.html`. Общая навигация: `src/header.html`, `src/footer.html`. Каталог: `src/programs.json`; без `url` карточка выводится текстом. Единственная подготовленная подробная страница — `course.html`; не присваивать другим программам тот же шаблон с её содержанием.

Исходные сборки верстальщика (Tailwind и плагины) отсутствуют. Базовые стили и скрипты сохранены в `css/style.css` и `js/app.js`; новые правила и поведение — в `src/site.css` и `src/site.js`. Команда сборки создаёт минифицированные файлы и обновляет версии ссылок. Продакшен: `SITE_URL=https://t-university-landing.pages.dev/ NODE_ENV=production npm run build && npm test`. В Cloudflare Pages этот адрес используется по умолчанию; если `SITE_URL` уже задан в настройках проекта, обновите его там. Допускается подпапка в `SITE_URL`. Опубликовать готовые HTML, `robots.txt`, `sitemap.xml`, каталоги `data/`, `css/`, `js/`, `fonts/`, `img/`. Для сайта в подпапке директиву Sitemap перенести в robots.txt корня домена. Настроить 301 с index.html на каноническую главную. Локальная сборка без `SITE_URL` не генерирует sitemap или canonical. После публикации отправить sitemap в Яндекс Вебмастер и Google Search Console, проверить публичный URL и `img/social-card.png` без авторизации.

Афиша: источник — публичный `data/events.json`. Каждая запись: `title`, `description`, `place`, `start` в формате YYYY-MM-DD; необязательные `end` (последний день включительно), `time` (HH:MM, московское время), `url` (HTTPS-регистрация). Для новой записи достаточно обновить JSON на хостинге: при следующем открытии страницы афиша загрузится автоматически. Пересобирайте при публикации изменений, чтобы статический HTML для поисковиков и посетителей без JS также был актуален. Истекшие события скрываются из афиши по московской дате. При ошибке загрузки сохраняется HTML последней сборки.

Перед публикацией сверить названия и коды направлений с приёмной комиссией: исходный каталог повторяет `08.03.01`. Для мероприятий, WhatsApp и политики конфиденциальности нужны утверждённые адреса; ссылки-заглушки удалены.
